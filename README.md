# Fruity Fun Fruit Drink — Premium 3D Animated Website

A modern, production-quality, visually stunning 3D animated website built for **Fruity Fun Fruit Drink**, celebrating its two signature flavours: **Mango Magic (200 ml)** and **Apple Freshness (200 ml)**.

---

- **Brand Name**: Fruity Fun Fruit Drink
- **Official Email**: `thefruityfun@gmail.com`

- **Current Flavours**:
  - **Mango Fruit Drink — 200 ml Carton**: Golden sunshine sweetness, velvety smooth finish.
  - **Apple Fruit Drink — 200 ml Carton**: Orchard-crisp freshness, zesty refreshing balance.
- **Packaging Integrity**: Authentic 200 ml aseptic cartons modeled and textured with real packaging graphics, fold creases, and straw puncture foil.

---

## 🚀 Key Features

1. **Cinematic 3D Hero Scene**:
   - Built with **Three.js** featuring realistic 3D models of both 200 ml aseptic juice cartons.
   - PBR materials with realistic semi-gloss packaging sheen, contact shadows, and 3-point studio commercial lighting.
   - Interactive 360° mouse drag / touch rotation and smooth cursor parallax.
   - Ambient floating fruit slices, fresh green leaves, and glossy translucent liquid splash droplets.
   - Duo / Solo focus toggle with smooth camera transitions.

2. **Our Flavours Section**:
   - Interactive 3D tilt cards with perspective physics on mouse hover.
   - Authentic packaging presentations with extracted real fruit graphics (sliced mango cubes, fresh orchard apples, leaves).
   - Sensory notes and taste balance meters (Sweetness, Fruitiness, Crispness).

3. **Interactive 3D Product Showcase**:
   - Real-time flavour switcher between Mango Magic and Apple Freshness.
   - Smooth animated background color transitions matching each flavour's vibrant palette.
   - Interactive 3D single-product inspector with 360° rotation angle readout.
   - Packaging specifications and interactive fruit confetti celebration.

4. **Brand Experience Section**:
   - Editorial showcase centered on **“Real Fruit Vibes. Fruity Fun Moments.”**
   - Clean, spacious 3-pillar layout highlighting Big Fruit Flavour, Everyday Fun Moments, and Convenient 200 ml Aseptic Packaging.

5. **Closing CTA & Verified Footer**:
   - Dual-carton celebratory layout: *“Which Flavour Is Your Favourite?”*
   - Direct navigation buttons for each flavour.
   - Clean, verified footer containing only the official contact details (`mailto:thefruityfun@gmail.com` and Facebook link).

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite 8
- **Styling**: Tailwind CSS v4 with custom glassmorphism & typography
- **3D Graphics**: Three.js (WebGL PBR Materials, Directional / Point / Rim Studio Lighting, PCF Soft Shadows)
- **Icons**: Lucide React
- **Micro-Interactions**: Canvas Confetti

---

## 💻 Running the Project

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
```
